# Branding integration

The Baby Monitor logo is now visible on the onboarding screen, the primary crying-analysis screen, and the home app bar. It uses the reusable SVG asset and keeps the requested visual: a cartoon baby in a diaper, sound waves from the baby's mouth, and a smiling mother's ear.

The current recording screen is a safe UI prototype. It does not claim to classify a baby's needs until a validated, secure audio-analysis backend is connected.
